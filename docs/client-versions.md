# 클라이언트 최소 버전

게이트는 배포 목록의 `minimum`을 최소 버전으로 쓴다. 요청의 `x-croak-client-version`이 없으면 HTTP 426을 돌려준다. 최소 버전보다 낮아도 426을 돌려준다. 응답은 `croakcode upgrade`를 안내한다.

Caddy는 공개 API 요청을 로그인 서비스에 먼저 확인한다. 로그인 서비스도 토큰 발급과 갱신, 계정 조회, 로그아웃을 검사한다. 실행 허가와 모델 목록 요청도 검사한다. 브라우저 로그인 화면과 상태 확인, 다운로드 경로에는 버전 머리글이 필요 없다.

배포 목록을 읽지 못하면 API 요청은 HTTP 503으로 중단한다. 목록의 내용이 잘못된 경우에도 중단한다. 목록의 최소 버전이 바뀌면 다음 요청부터 적용한다. 개발 버전은 같은 번호의 정식 버전보다 낮게 본다.

## 적용 순서

이 변경을 운영에 배포하기 전에 새 클라이언트를 모든 PC에 설치한다. 서버의 다운로드 폴더에는 유효한 배포 목록을 둔다. 이 순서를 지키지 않으면 기존 클라이언트의 로그인과 API 요청이 차단된다. 운영 배포는 관리자가 실행한다.
